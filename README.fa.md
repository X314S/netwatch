# NetWatch

[نسخهٔ English](README.md) · **فارسی**

**NetWatch** یک برنامهٔ دسکتاپ سبک برای ویندوز است که برای پایش شبکه طراحی شده است؛ آداپتورهای شبکه، سرعت لحظه‌ای اینترنت، اطلاعات IP، پایش Ping، اتصالات هر Process، ابزارهای شبکه و ابزارهای تشخیصی، همگی در یک Dashboard مدرن در دسترس هستند.

**پلتفرم:** ویندوز ۱۰ و ۱۱

---

## ✨ قابلیت‌ها

- 📊 **Dashboard زنده:** سرعت لحظه‌ای دانلود و آپلود، نمودار زنده، مجموع مصرف شبکه (سیستم + همین برنامه)، کارت جغرافیایی IP عمومی و Processهای پرترافیک
- 🖧 **آداپتورهای شبکه:** وضعیت، نوع، سرعت Link، IPها، انتخاب آداپتور فعال و مدیریت DNS
- 🌐 **اطلاعات IP:** IPv4/IPv6 محلی و IP عمومی همراه با کشور، شهر و ISP
- 📶 **مانیتور Ping:** هدف‌های دلخواه و Presetهای قابل‌جست‌وجو برای DNS و وب‌سایت‌های معروف؛ نمایش زندهٔ Min/Max/Avg و درصد Packet Loss
- ⚙️ **اتصالات فعال:** جدول Socketهای TCP/UDP هر Process با فیلتر Protocol، نقاط ترافیک زنده، شمارنده‌های خلاصه و یک Inspector درون‌خطی برای Ping، مکان، Port و rDNS
- 🧰 **ابزارهای شبکه:** DNS/ARP/Routing، Traceroute، اسکنرهای Port/LAN/Wi-Fi، Whois، WOL، بررسی‌کنندهٔ SSL، تست HTTP، ویرایشگر hosts، Flush DNS، Reset Network و مدیریت Firewall؛ همراه با Snapshot و Undo
- 🚀 **تست سرعت:** دانلود، آپلود و Latency واقعی از **Cloudflare، Fast.com یا Ookla**؛ نمایش زندهٔ مراحل Starting → Latency → Download → Upload، سرعت لحظه‌ای برحسب Mbps، تایمر و دکمهٔ Cancel
- 🖼️ **مینی-HUD:** نوار شناور همیشه‌روی‌صفحه برای نمایش سرعت، Ping و مصرف که به لبهٔ بالایی می‌چسبد، امکان Lock شدن دارد، روی Monitor دلخواه کار می‌کند، Transparency و Click-through را تنظیم می‌کند و پنل **Process Watch** را در اختیار شما قرار می‌دهد
- 🛡️ **تشخیص VPN:** هشدارهای هوشمند، **تاریخچهٔ Eventها** و Restore Pointها
- 🖥️ **System Tray:** امکان بستن پنجره به Tray، مصرف کم منابع در پس‌زمینه و Global Hotkeyهای (`Ctrl+Alt+N/H/L`)
- 🔄 **به‌روزرسانی درون‌برنامه‌ای:** اطلاع‌رسانی داخل برنامه هنگام انتشار نسخهٔ جدید و امکان به‌روزرسانی با یک کلیک
- 🔒 **بدون نیاز به اینترنت:** هستهٔ برنامه بدون اینترنت کار می‌کند؛ فقط قابلیت‌های IP عمومی، Geolocation و Speed Test به اتصال اینترنت نیاز دارند.

## 🚀 نصب و استفاده (برای کاربران)

1. **آخرین Release** را از [صفحهٔ Releases](https://github.com/X314S/netwatch/releases) دانلود و فایل ZIP را Extract کنید؛ یک پوشهٔ `NetWatch` خواهید داشت. می‌توانید این پوشه را هر جا که می‌خواهید قرار دهید، برای مثال در `C:\NetWatch`.
2. **فایل `NetWatch.exe`** را از داخل پوشه اجرا کنید. تمام! نیازی به نصب Python یا Node نیست.

> **WebView2:** رابط کاربری از WebView2 ویندوز استفاده می‌کند که در بیشتر موارد همراه با ویندوز ۱۰ و ۱۱ نصب شده است. اگر WebView2 روی سیستم موجود نباشد، Installer همراه برنامه از داخل پوشهٔ `redist` به‌صورت خودکار اجرا می‌شود.

### اولین اجرا

- پنجرهٔ برنامه باز می‌شود و NetWatch هم‌زمان در **System Tray**، کنار ساعت، اجرا می‌شود.
- با بستن پنجره، برنامه به System Tray منتقل می‌شود و پایش شبکه ادامه پیدا می‌کند. برای خروج کامل، روی آیکون برنامه در System Tray راست‌کلیک کرده و گزینهٔ **Exit** را انتخاب کنید.

## 🖥️ استفاده از برنامه

| بخش | کارکرد |
|---------|--------------|
| **Dashboard** | نمای کلی شامل سرعت، IP، Ping و Processهای پرترافیک |
| **Network** | آداپتورها، DNS، اتصالات فعال و Speed Test |

### به‌روزرسانی‌ها

- برنامه هنگام Startup و همچنین با استفاده از دکمهٔ **Check** در Settings، GitHub را برای یافتن نسخهٔ جدید بررسی می‌کند.
- در صورت وجود نسخهٔ جدید، دکمهٔ **Update vX** در نوار بالایی ظاهر می‌شود؛ سپس با انتخاب آن، فایل دانلود شده و گزینهٔ **Install & Restart** در دسترس قرار می‌گیرد.

## ✅ تأیید صحت دانلود

هر Release، در کنار فایل ZIP، یک فایل `SHA256SUMS` دارد. پیش از اجرای برنامه، صحت فایل دانلودشده را بررسی کنید.

**روش بررسی در ویندوز با PowerShell:**

```powershell
# خروجی را با Hash موجود در SHA256SUMS مقایسه کنید
certutil -hashfile NetWatch-portable-<version>.zip SHA256
```

**روش بررسی در ویندوز، لینوکس و macOS با sha256sum:**

```bash
# فایل SHA256SUMS را از Release دانلود کنید و دستور زیر را اجرا کنید:
sha256sum -c SHA256SUMS        # → "NetWatch-portable-<version>.zip: OK"
```

خود برنامه نیز پیش از اعمال به‌روزرسانی درون‌برنامه‌ای، این Checksum را دوباره بررسی می‌کند؛ بنابراین Archive نامطابق هرگز اعمال نخواهد شد.

## 🔒 حریم خصوصی

**NetWatch چه کاری انجام نمی‌دهد:** این برنامه هیچ سیستم Account، کلید API یا سازوکار جمع‌آوری و ذخیرهٔ داده‌های شخصی ندارد. تمام داده‌هایی که برنامه نمایش می‌دهد، از جمله آداپتورها، ترافیک، اتصالات هر Process، تنظیمات DNS، فایل hosts، History و Restore Pointها، از طریق APIهای محلی ویندوز جمع‌آوری شده و **فقط روی دستگاه شما** ذخیره می‌شوند، در پوشهٔ دادهٔ محلی برنامه. هیچ‌کدام از این داده‌ها به جایی ارسال نمی‌شوند.

**فهرست کامل درخواست‌های خروجی**؛ به‌جز موارد زیر، هیچ دادهٔ دیگری از دستگاه شما خارج نمی‌شود:

| قابلیت | محل اتصال | چه چیزی ارسال می‌شود |
|---|---|---|
| IP عمومی / کارت جغرافیایی | `ip-api.com` و جایگزین‌های `ipwho.is`، `ipapi.co` و `ipify` | آدرس IP عمومی شما؛ این مورد برای ارائهٔ قابلیت مذکور ضروری است |
| بررسی Update | `api.github.com` (`X314S/netwatch`) | فقط خودِ درخواست |
| بنر تبلیغاتی | Cloudflare Worker | شناسهٔ Campaign تبلیغاتی و تصویر Banner |
| Ping روزانهٔ ناشناس | Cloudflare Worker | یک شناسهٔ نصب تصادفی و ناشناس به‌همراه نسخهٔ برنامه؛ هیچ دادهٔ دیگری ارسال نمی‌شود |
| Speed Test / Whois / SSL / HTTP / DNS | سرورهایی که خودتان انتخاب می‌کنید | فقط داده‌ای که ابزار اجراشده برای مقصد انتخابی شما ارسال می‌کند |

### Ping روزانهٔ ناشناس — به زبان ساده

هیچ دادهٔ شخصی ارسال نمی‌شود. فقط روزی یک‌بار، یک شناسهٔ تصادفی و ناشناس که روی دستگاه شما ساخته می‌شود، به‌همراه نسخهٔ برنامه ارسال می‌شود تا توسعه‌دهنده بتواند تعداد نصب‌های فعال را محاسبه کند. همین و بس؛ بدون نام، بدون IP، بدون مشخصات دستگاه و بدون دادهٔ مربوط به نحوهٔ استفاده.

## ⚠️ سلب مسئولیت

**NetWatch** یک **ابزار نمایش و تشخیص شبکه** است و به‌صورت **«همان‌طور که هست»، بدون هیچ‌گونه ضمانتی** — چه صریح و چه ضمنی، از جمله ضمانت تناسب برای هدفی خاص — ارائه می‌شود.

- مسئولیت نحوهٔ استفاده از برنامه کاملاً بر عهدهٔ شماست. **هرگونه استفادهٔ نادرست از ابزارها، از جمله تغییر Firewall، Reset Network، ویرایش فایل hosts، اجرای دستورات با سطح دسترسی Administrator یا Kill کردن Process بر اساس اطلاعات ناقص، کاملاً بر عهدهٔ کاربر است** و ممکن است باعث اختلال در سیستم یا شبکهٔ شما شود.
- سازنده یا تیم توسعه **هیچ مسئولیتی** در قبال خسارت، از دست رفتن داده‌ها یا اختلال ناشی از استفاده یا سوءاستفاده از نرم‌افزار و قابلیت‌های آن ندارد.
- پیش از انجام اقدامات مخرب، صحت آن‌ها را تأیید کنید. برنامه برای بیشتر تغییرات سیستمی دارای Restore Point است؛ از آن استفاده کنید.

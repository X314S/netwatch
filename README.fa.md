# NetWatch

[English](README.md) · **فارسی**

**NetWatch** یک برنامه‌ی دسکتاپ سبک و «آفلاین-اول» ویندوزی برای مانیتورینگ شبکه است — آداپتورهای شبکه، سرعت لحظه‌ای اینترنت، اطلاعات IP، مانیتورینگ پینگ، اتصالات هر پروسه، یک جعبه‌ابزار شبکه و ابزارهای تشخیصی؛ همه در یک داشبورد مدرن.

**پلتفرم:** Windows 10/11

---

## ✨ قابلیت‌ها

- 📊 **داشبورد زنده:** سرعت لحظه‌ای دانلود/آپلود، نمودار زنده، مجموع مصرف (سیستم + همین برنامه)، کارت جغرافیای IP عمومی و پردازه‌های پرترافیک
- 🖧 **آداپتورهای شبکه:** وضعیت، نوع، سرعت لینک، IPها، انتخاب آداپتور فعال + مدیریت DNS
- 🌐 **اطلاعات IP:** IPv4/IPv6 محلی + IP عمومی با کشور / شهر / ISP
- 📶 **مانیتور پینگ:** هدف‌های دلخواه + پری‌ست‌های قابل‌جست‌وجوی DNS/وب‌سایت‌های معروف؛ Min/Max/Avg و درصد پاکت‌لاس زنده
- ⚙️ **اتصالات فعال:** جدول سوکت‌های TCP/UDP هر پردازه با فیلتر پروتکل، نقطه‌های ترافیک زنده، شمارنده‌های خلاصه و یک Inspector درون‌خطی (پینگ / مکان / پورت / rDNS)
- 🧰 **جعبه‌ابزار شبکه:** DNS/ARP/Routing، Traceroute، اسکنرهای Port / LAN / Wi‑Fi، Whois، WOL، بررسی‌کننده‌ی SSL، تست HTTP، ویرایشگر hosts / فلاش DNS / ریست شبکه / مدیریت فایروال — همراه با اسنپ‌شات و Undo
- 🚀 **تست سرعت:** دانلود / آپلود / تأخیر واقعی از **Cloudflare، Fast.com یا Ookla** — بازخورد زنده‌ی فاز (Starting → Latency → Download → Upload)، مگابیت لحظه‌ای، تایمر و دکمه‌ی Cancel
- 🖼️ **مینی-HUD:** نوار شناور همیشه-در-بالای سرعت/پینگ/مصرف که به لبه‌ی بالا می‌چسبد، قابل قفل‌کردن است، روی مانیتور دلخواه کار می‌کند، شفافیت/کلیک-از-میان‌را تنظیم می‌کند و پنل **Process Watch** دارد
- 🛡️ **تشخیص VPN**، هشدارهای هوشمند + **تاریخچه‌ی رویدادها** و نقاط بازیابی
- 🖥️ **سیستم‌ترِی:** بستن به ترِی، مصرف کم در پس‌زمینه، کلیدهای میان‌بر سراسری (`Ctrl+Alt+N/H/L`)
- 🔄 **آپدیت درون‌برنامه‌ای:** اطلاع‌رسانی داخل برنامه هنگام انتشار نسخه‌ی جدید؛ آپدیت با یک کلیک
- 🔒 **آفلاین-اول:** هسته بدون اینترنت کار می‌کند (فقط IP عمومی، جغرافیا و تست سرعت قابلیت‌های آنلاین اختیاری‌اند)

## 🚀 نصب و استفاده (برای کاربران)

1. **آخرین ریلیز** را از [صفحه‌ی Releases](https://github.com/X314S/netwatch/releases) دانلود و zip را extract کنید — یک پوشه‌ی `NetWatch` می‌گیرید (هرجا می‌خواهید بگذارید، مثلاً `C:\NetWatch`).
2. **`NetWatch.exe`** را داخل آن اجرا کنید. تمام — نیازی به Python یا Node نیست.

> **WebView2:** رابط کاربری از WebView2 ویندوز استفاده می‌کند که در بیشتر موارد همراه Windows 10/11 هست. اگر نبود، برنامه نصب‌کننده‌ی همراه (داخل پوشه‌ی `redist`) را خودکار اجرا می‌کند.

### اولین اجرا
- پنجره باز می‌شود و NetWatch هم‌زمان در **سیستم‌ترِی** (کنار ساعت) زندگی می‌کند.
- بستن پنجره، برنامه را به ترِی می‌برد (مانیتورینگ ادامه دارد). برای خروج کامل: راست‌کلیک روی آیکون ترِی → **Exit**.

## ✅ تایید صحت دانلود

هر ریلیز کنار فایل zip یک فایل `SHA256SUMS` دارد. قبل از اجرا، صحت فایل دانلودشده را تایید کنید:

**ویندوز (PowerShell):**
```powershell
# خروجی را با هش داخل SHA256SUMS مقایسه کنید
certutil -hashfile NetWatch-portable-<version>.zip SHA256
```

**ویندوز / لینوکس / مک (sha256sum):**
```bash
# SHA256SUMS را از ریلیز دانلود کنید و اجرا کنید:
sha256sum -c SHA256SUMS        # → "NetWatch-portable-<version>.zip: OK"
```

خود برنامه نیز قبل از اعمال آپدیت درون‌برنامه‌ای این checksum را دوباره بررسی می‌کند — بایگانی نامطابق هرگز اعمال نمی‌شود.

## 🔒 حریم خصوصی

**NetWatch چه کاری انجام نمی‌دهد:** هیچ سیستم اکانتی، هیچ کلید API و هیچ جمع‌آوری یا ذخیره‌ی داده‌ی شخصی ندارد. تمام داده‌هایی که برنامه نمایش می‌دهد — آداپتورها، ترافیک، اتصالات هر پردازه، تنظیمات DNS، فایل hosts، تاریخچه، نقاط بازیابی — از طریق API های محلی ویندوز جمع‌آوری و **فقط روی دستگاه شما** ذخیره می‌شود (در پوشه‌ی داده‌ی محلی برنامه). هیچ‌کدام از این داده‌ها به جایی ارسال نمی‌شود.

**فهرست کامل درخواست‌های خروجی** (و جز این‌ها هیچ چیز دستگاه شما را ترک نمی‌کند):

| قابلیت | محل اتصال | چه چیزی ارسال می‌شود |
|---|---|---|
| IP عمومی / کارت جغرافیا | `ip-api.com` (+ جایگزین‌ها `ipwho.is`، `ipapi.co`، `ipify`) | آدرس IP عمومی شما (ذاتی این قابلیت) |
| بررسی به‌روزرسانی | `api.github.com` (X314S/netwatch) | فقط خودِ درخواست |
| بنر تبلیغ | Cloudflare Worker | شناسه‌ی کمپین تبلیغ + تصویر بنر |
| پینگ روزانه‌ی ناشناس | Cloudflare Worker | یک شناسه‌ی نصب تصادفی ناشناس + نسخه‌ی برنامه — هیچ چیز دیگر (پایین) |
| تست سرعت / Whois / SSL / HTTP / DNS | سرورهایی که خودتان انتخاب می‌کنید | فقط همان چیزی که ابزارِ اجراشده به مقصد انتخابی شما می‌فرستد |

### پینگ روزانه‌ی ناشناس — به زبان ساده

هیچ داده‌ای ارسال نمی‌شود. فقط روزی یک‌بار یک شناسه‌ی تصادفی ناشناس (که روی دستگاه شما ساخته می‌شود) + نسخه‌ی برنامه فرستاده می‌شود تا توسعه‌دهنده بتواند تعداد نصب‌های فعال را بشمارد. همین و بس — بدون نام، بدون IP، بدون مشخصات دستگاه یا داده‌ی استفاده.

## ⚠️ سلب مسئولیت

NetWatch یک **ابزار نمایش و تشخیص شبکه** است و **«همان‌طور که هست» (AS IS)** و بدون هرگونه تضمین — صریح یا ضمنی، از جمله تناسب برای هدف خاص — ارائه می‌شود.

- مسئولیت نحوه‌ی استفاده کاملاً با شماست. **هرگونه استفاده‌ی نادرست از ابزارها (تغییر فایروال، ریست شبکه، ویرایش hosts، دستورات سطح Administrator یا Kill کردن پردازه بر اساس اطلاعات ناقص) به‌طور کامل بر عهده‌ی کاربر است** و ممکن است سیستم یا شبکه‌ی شما را مختل کند.
- سازنده/تیم توسعه **هیچ مسئولیتی** در قبال خسارت، از دست رفتن داده یا اختلال ناشی از استفاده — یا سوءاستفاده — از نرم‌افزار و قابلیت‌های آن ندارد.
- پیش از اقدامات مخرب تأیید کنید؛ برنامه برای اکثر تغییرات سیستمی نقطه‌ی بازیابی (Restore) دارد — از آن استفاده کنید.
